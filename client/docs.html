About the API

The BookShelf API allows users to retrieve, search, add, and update books from a collection of book data. It also provides random book recommendations.

All API endpoints use relative URLs and return JSON responses. GET endpoints also support HEAD requests. POST endpoints accept JSON and URL encoded form data.

GET Endpoints

Use these endpoints to retrieve books and recommendations.

1. Get Books

Retrieves books from the collection. An optional limit parameter controls the maximum number of books returned.

Endpoint: /getBooks

Methods: GET, HEAD

Response Format: JSON

Query Parameters

Parameter Type Required? Description
limit Number No Maximum number of books to return.

Request Body

None required.

Example Request

GET /getBooks?limit=2

Example Response (200 OK)

{
  "books": [
    {
      "title": "Book Title",
      "author": "Author Name",
      "genres": ["Fiction"]
    },
    {
      "title": "Another Book",
      "author": "Another Author",
      "genres": ["Adventure"]
    }
  ]
}

Possible Status Codes

200 OK — Books retrieved successfully.
400 Bad Request — Invalid limit parameter.

Note: HEAD requests return the same response headers as GET, but without a response body.

2. Get Book by Title

Retrieves a specific book from the collection using its title. The title search is case-insensitive.

Endpoint: /getBook

Methods: GET, HEAD

Response Format: JSON

Query Parameters

Parameter Type Required? Description
title String Yes Title of the book to retrieve.

Request Body

None required.

Example Request

GET /getBook?title=Pride%20and%20Prejudice

Example Response (200 OK)

{
  "book": {
    "title": "Pride and Prejudice",
    "author": "Jane Austen",
    "country": "United Kingdom",
    "language": "English",
    "pages": 226,
    "year": 1813,
    "genres": ["Romance"]
  }
}

Possible Status Codes

200 OK — Book retrieved successfully.
400 Bad Request — Missing title parameter.
404 Not Found — No matching book exists.

Note: HEAD requests return response headers without a response body.

3. Get Books by Author

Retrieves all books written by a specified author. The author search is case-insensitive.

Endpoint: /getBooksByAuthor

Methods: GET, HEAD

Response Format: JSON

Query Parameters

Parameter Type Required? Description
author String Yes Name of the author to search for.

Request Body

None required.

Example Request

GET /getBooksByAuthor?author=Jane%20Austen

Example Response (200 OK)

{
  "books": [
    {
      "title": "Pride and Prejudice",
      "author": "Jane Austen",
      "genres": ["Romance"]
    },
    {
      "title": "Emma",
      "author": "Jane Austen",
      "genres": ["Romance"]
    }
  ]
}

Possible Status Codes

200 OK — Matching books retrieved successfully.
400 Bad Request — Missing author parameter.
404 Not Found — No books found for that author.

Note: HEAD requests return response headers without a response body.

4. Get Books by Genre

Retrieves all books belonging to a specified genre. The genre search is case-insensitive.

Endpoint: /getBooksByGenre

Methods: GET, HEAD

Response Format: JSON

Query Parameters

Parameter Type Required? Description
genre String Yes Genre to search for, such as Romance or Fantasy.

Request Body

None required.

Example Request

GET /getBooksByGenre?genre=Romance

Example Response (200 OK)

{
  "books": [
    {
      "title": "Pride and Prejudice",
      "author": "Jane Austen",
      "genres": ["Romance"]
    },
    {
      "title": "Example Romance Novel",
      "author": "Example Author",
      "genres": ["Romance", "Fiction"]
    }
  ]
}

Possible Status Codes

200 OK — Matching books retrieved successfully.
400 Bad Request — Missing genre parameter.
404 Not Found — No books found for that genre.

Note: HEAD requests return response headers without a response body.

5. Get Random Book Recommendation

Retrieves a randomly selected book from the collection. Users can optionally specify a genre to receive a recommendation from that category.

Endpoint: /getRandomBook

Methods: GET, HEAD

Response Format: JSON

Query Parameters

Parameter Type Required? Description
genre String No Limits the random recommendation to books belonging to the specified genre.

Request Body

None required.

Example Requests

GET /getRandomBook

GET /getRandomBook?genre=Romance

Example Response (200 OK)

{
  "book": {
    "title": "Pride and Prejudice",
    "author": "Jane Austen",
    "country": "United Kingdom",
    "language": "English",
    "pages": 226,
    "year": 1813,
    "genres": ["Romance"]
  }
}

Possible Status Codes

200 OK — Random book retrieved successfully.
404 Not Found — No books match the specified genre.

Note: HEAD requests return response headers without a response body.

POST Endpoints

Use these endpoints to add or update books in the collection.

6. Add a Book

Adds a new book to the collection. A title and author are required, while additional book details are optional. Newly added books are stored in memory and will not persist after the server restarts.

Endpoint: /addBook

Method: POST

Response Format: JSON

Query Parameters

None required.

Request Body Parameters

Parameter Type Required? Description
title String Yes Title of the new book.
author String Yes Author of the book.
country String No Country associated with the book.
language String No Language of the book.
link String No Optional link to additional information.
pages Number No Number of pages.
year Number No Year the book was published.
genres Array or String No Book genres. Use an array for JSON requests or a comma-separated string for form submissions.

Supported Content Types

application/json and application/x-www-form-urlencoded

Example Request

POST /addBook
Content-Type: application/json

{
  "title": "The Secret Garden",
  "author": "Frances Hodgson Burnett",
  "country": "United Kingdom",
  "language": "English",
  "pages": 375,
  "year": 1911,
  "genres": ["Fiction", "Children's Literature"]
}

Example Response (201 Created)

{
  "message": "Book added successfully.",
  "book": {
    "title": "The Secret Garden",
    "author": "Frances Hodgson Burnett",
    "country": "United Kingdom",
    "language": "English",
    "pages": 375,
    "year": 1911,
    "genres": ["Fiction", "Children's Literature"]
  }
}

Possible Status Codes

201 Created — Book added successfully.
400 Bad Request — Missing required fields, invalid JSON, or unsupported request content type.

7. Update a Book

Updates an existing book in the collection using its title. The title is required to identify the book, while all other fields are optional. Changes are stored in memory and will not persist after the server restarts.

Endpoint: /updateBook

Method: POST

Response Format: JSON (except 204 responses)

Query Parameters

None required.

Request Body Parameters

Parameter Type Required? Description
title String Yes Title of the existing book to update.
author String No Updated author name.
country String No Updated country.
language String No Updated language.
link String No Updated information link.
pages Number No Updated page count.
year Number No Updated publication year.
genres Array or String No Updated genres. Use an array for JSON requests or a comma-separated string for form submissions.

Supported Content Types

application/json and application/x-www-form-urlencoded

Example Request

POST /updateBook
Content-Type: application/json

{
  "title": "Pride and Prejudice",
  "pages": 300,
  "genres": ["Romance", "Classic"]
}

Example Response (200 OK)

{
  "message": "Book updated successfully.",
  "book": {
    "title": "Pride and Prejudice",
    "author": "Jane Austen",
    "pages": 300,
    "genres": ["Romance", "Classic"]
  }
}

The response above is abbreviated. The actual API returns the complete updated book object.

Possible Status Codes

200 OK — Book updated successfully.
204 No Content — No update fields were provided.
400 Bad Request — Missing title, invalid JSON, or unsupported request content type.
404 Not Found — No book matches the provided title.

Note: A 204 response has no response body.
